UI Components

Reusable PixiJS UI components built on @pixi/layout and @pixi/ui. Each accepts a JSON-serializable preset object so configuration can be stored as Text assets and overridden per app.

ButtonComponent

Pressable button with a rounded-rect placeholder that can be replaced by a texture, plus an optional centered label.

const btn = new ButtonComponent({
  width: 400, height: 200,
  label: "PLAY",
  bgTextureId: "MainScreen.PlayButtonBg",
});
btn.resolveAssets(assetManager);
btn.onPress(() => { /* ... */ });

Preset: x, y, width, height, label, labelStyle, radius (12), fillColor, fillAlpha, strokeColor, strokeWidth, bgTextureId.

Methods: setTexture(), setLabel(), onPress(cb): Unsubscribe, resolveAssets(assetManager).

BackgroundComponent

Full-screen cover-fit background with overlay and fallback color.

Preset: bgTextureId, overlayColor (0x000000), overlayAlpha (0.12), fallbackColor (0x020617), fallbackAlpha (0.55).

ImageComponent

Texture fitted into a layout-managed box with configurable scaling.

Preset: x, y, width, height, textureId, fit ("contain"/"cover"/"stretch"), padding (0–1).

VerticalLayoutComponent

Flex column container. Preset: x, y, width, height, gap, padding, alignItems, justifyContent.

HorizontalLayoutComponent

Flex row container with optional absolute positioning. Same preset as vertical plus position, left, top, right, bottom.

JSON preset pattern

Every component has a parse*Preset(json) helper. Store presets as Text assets and override per app:

// In ModuleBinding:
this._assetRequestList.addRequest(
  new AssetRequest(AssetTypes.Text, MyAssetIds.MyBtnPreset, "",
    '{"width":400,"height":200,"label":"PLAY"}')
);

// In View:
const json = this.assetLoader.getAsset<string>(MyAssetIds.MyBtnPreset) ?? "{}";
const button = new ButtonComponent(parseButtonComponentPreset(json));

Use UIUtils.updateFields(baseJson, overridesJson) to tweak individual fields.

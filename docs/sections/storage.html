Storage

StorageService provides simple key-value persistence backed by localStorage. Keys are automatically prefixed to avoid collisions between games on the same domain.

Usage

// In configureDI:
const storage = new StorageService("MyGame");
this.diContainer.bindInstance(StorageService, storage);

// In a controller or utility:
storage.save("highScore", 42);
const score = storage.load<number>("highScore"); // 42 or null

storage.has("highScore");  // true
storage.remove("highScore");
storage.clear();           // removes all "MyGame.*" keys

API

  • constructor(prefix) — namespaces all keys (e.g. "MyGame" → stored as "MyGame.highScore")
  • save<T>(key, value) — JSON-serializes and writes to localStorage
  • load<T>(key): T | null — reads and parses; returns null on miss or error
  • has(key): boolean — check existence
  • remove(key) — delete one key
  • clear() — delete all keys with this prefix

All methods silently handle localStorage being unavailable or full.

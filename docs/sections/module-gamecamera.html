Game Camera

Controls the 3D scene camera in Three.js. Supports multiple projection modes, object/position following, and smooth easing.

Usage

const cameraBinding = new GameCameraBinding();
this.addModule(cameraBinding);

// In postInitialize:
cameraBinding.cameraManager.initialize(this.world);
const controller = new Topdown2dCameraController(cameraBinding.cameraManager);
controller.followPosition(0, 0, 0);
cameraBinding.cameraManager.setOrthoSize(20);

// In onResize:
cameraBinding.cameraManager.resize(width, height);

// In onStep:
cameraBinding.cameraManager.update(dtSeconds);

Camera modes

  • Front 2D/3D — orthographic/perspective facing -Z
  • Topdown 2D/3D — orthographic/perspective facing -Y
  • Isometric 2D/3D — orthographic/perspective from (a,a,a) toward origin
  • Orbital 3D — perspective spherical orbit with distance, azimuth, pitch controls
  • Custom — extend BaseCustomCameraController

Common API

  • followObject(mesh, ease?) — smooth follow a 3D object
  • followPosition(x, y, z, ease?) — smooth follow a point
  • setPosition(x, y, z) — instant position
  • setOrthoSize(size) — orthographic visible height
  • activate() / deactivate() — toggle updates

Audio DSP

Audio effects built on the Web Audio API. Chain multiple effects in series and apply them to SFX or music channels via AudioManager.

DspChain

A serial chain of effects. Audio flows through each effect in order.

const chain = new DspChain(audioManager.context!);
chain.addEffect(new FilterEffect({ type: "lowpass", frequency: 800 }));
chain.addEffect(new DelayEffect({ time: 0.2, feedback: 0.3 }));

// Wire into AudioManager
chain.connectTo(audioManager.sfxGain!);
audioManager.setSfxDestination(chain.input);

// Remove chain
audioManager.setSfxDestination(null);
chain.destroy();

Effects

FilterEffect — biquad filter (low-pass, high-pass, bandpass, etc.)

new FilterEffect({ type: "lowpass", frequency: 1000, Q: 2 })
// Real-time sweep:
filter.setFrequency(200, 500); // ramp to 200Hz over 500ms

ReverbEffect — convolution reverb using an impulse response AudioBuffer.

const reverb = new ReverbEffect({ impulseAssetId: "MyGame.CaveIR", mix: 0.6 });
// After assets loaded:
reverb.resolveAssets(assetManager);

DelayEffect — delay with feedback loop.

new DelayEffect({ time: 0.3, feedback: 0.4, mix: 0.5 })

DistortionEffect — waveshaper distortion with tanh curve.

new DistortionEffect({ drive: 50, mix: 0.5 })

CompressorEffect — dynamics compressor to prevent clipping.

new CompressorEffect({ threshold: -24, ratio: 4, attack: 0.003, release: 0.25 })

All effects share

  • bypassed property — toggle effect on/off without removing from chain
  • setMix(0–1) — dry/wet blend (where applicable)
  • destroy() — disconnect and clean up nodes

DspPresets

One-liner factory methods for common scenarios:

DspPresets.underwater(ctx)       // low-pass 400Hz
DspPresets.occluded(ctx)         // low-pass 800Hz (behind wall)
DspPresets.echo(ctx)             // short delay + feedback
DspPresets.radio(ctx)            // bandpass + distortion
DspPresets.lofi(ctx)             // heavy distortion + high-pass
DspPresets.masterCompressor(ctx) // prevent clipping

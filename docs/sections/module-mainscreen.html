Main Screen

Main menu / title screen with a logo, play button, and settings button. Ready to use out of the box — register the module, wire events, and show the screen.

Usage

const mainScreenBinding = new MainScreenBinding();
this.addModule(mainScreenBinding);

// In postInitialize:
const events = this.diContainer.getInstance(MainScreenEvents);
events.onPlayClick(() => this.showLevelSelect());
events.onSettingsClick(() => this.openSettings());

uiEvents.createScreen(MainScreenUIIds.MainScreen, transition);

Asset overrides

Replace default assets before adding the module:

mainScreenBinding.assetRequestList.overrideRequest(
  MainScreenAssetIds.Logo, myLogoUrl
);
mainScreenBinding.assetRequestList.overrideRequest(
  MainScreenAssetIds.Background, myBgUrl
);

Events

  • MainScreenEvents.onPlayClick(cb) — play button tapped
  • MainScreenEvents.onSettingsClick(cb) — settings button tapped

Customization

  • Assets: override via assetRequestList.overrideRequest()
  • Button presets: override PlayButtonPreset / SettingsButtonPreset text assets
  • View: subclass MainScreenView and register your own binding
  • Events: bind your own MainScreenEvents instance in DI before the binding runs

File Naming Conventions

  • Interfaces: IFoo.ts
  • HUD views: FooView.pixi.ts
  • World views: FooView.three.ts
  • View controllers: FooViewController.ts — every controller in this codebase implements IViewController<IFooView>; the suffix stays explicit so concrete class names match the interface and disambiguate from other "controller" types like ICameraController
  • Events: FooEvents.ts
  • Models: Foo.ts or FooModel.ts
  • Config: MyGameConfig.ts
  • Asset IDs: MyGameAssetIds.ts — enum with namespaced values like "MyGame.ItemName"
  • UI IDs: MyGameUIIds.ts — enum with namespaced values like "MyGame.GameScreen"

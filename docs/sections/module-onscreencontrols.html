On-Screen Controls

Touch-friendly virtual controls rendered as a PixiJS HUD overlay. OnScreenControlManager implements IInputDeviceListener so controls integrate with InputMapper alongside keyboard.

Setup

const binding = new OnScreenControlsBinding();

binding.addControl({
  type: ControlType.Joystick,
  id: "move",
  anchor: ControlAnchor.BottomLeft,
  offsetX: 120, offsetY: 120,
  baseSize: 60, knobSize: 25,
  dynamic: false, threshold: 0.2,
});

binding.addControl({
  type: ControlType.Button,
  id: "fire",
  anchor: ControlAnchor.BottomRight,
  offsetX: 80, offsetY: 80,
  size: 70,
});

this.addModule(binding);

Create the view

// In your screen view's postInitialize():
this._controls = this.viewFactory.createView(OnScreenControlsView);
this.addChild(this._controls);

The view repositions itself on app resize (it subscribes via HudViewBase); calling this._controls.resize(width, height) from your screen's onResize is still supported but no longer required.

Map to InputMapper

mapper.addDeviceListener(binding.manager); // deviceId = "onscreen"

// Joystick virtual keys: <id>.up, <id>.down, <id>.left, <id>.right
mapper.mapKeysToDirection("onscreen",
  "move.up", "move.down", "move.left", "move.right", "move");

// Button: id is the key code
mapper.mapKeyToAction("onscreen", "fire", "shoot");

Virtual buttons

Circular touch targets with up/down visual states and optional icon textures.

Config: size, iconTextureId, upColor (0x222222), downColor (0x444444), upAlpha (0.5), downAlpha (0.8).

Virtual joysticks

Base circle + draggable knob. Fires virtual key press/release when the knob exceeds the threshold.

  • Static (dynamic: false) — always visible at the anchor position
  • Dynamic (dynamic: true) — hidden until touched; appears at finger position within the touch area

Config: baseSize, knobSize, dynamic, dynamicAreaWidth, dynamicAreaHeight, threshold (0.3), baseColor, baseAlpha, knobColor, knobAlpha.

Positioning

ControlAnchor enum positions controls relative to screen edges: TopLeft, TopCenter, TopRight, CenterLeft, Center, CenterRight, BottomLeft, BottomCenter, BottomRight. offsetX/offsetY move inward from the anchor.

Edge anchors respect the device safe area automatically: offsets are measured from IApp.safeAreaInsets (notch / home indicator) rather than the raw canvas edge, so controls stay tappable on notched phones. Center axes are unaffected. Disable app-wide with safeArea: false in the app config.

Runtime changes

Controls can be added or removed at any time via binding.addControl() / binding.removeControl(id). The view updates automatically through OnScreenControlEvents (controlAdded, controlRemoved).

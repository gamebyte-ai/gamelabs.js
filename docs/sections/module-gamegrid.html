Game Grid

Grid model, grid items, presets, and a view/controller pair for tile-based gameplay. Used by the match3, tictactoe, and 2048 examples.

Usage

const gridBinding = new GameGridBinding(MyGridsView, MyGridsViewController);
this.addModule(gridBinding);

// Access the model:
const model = gridBinding.model; // GridsModel
const grid = new Grid(id, cols, rows, gridEvents, preset);
model.addGrid(grid);

Core classes

  • Grid — a single grid instance with cells, items, and a preset (column/row size, axes)
  • GridsModel — stores multiple grids by ID
  • GridPreset — defines grid geometry (cell sizes, axis directions)
  • GridItem — base class for items placed in grid cells
  • GridEvents — emits cell/item change events
  • GridsView — Three.js world view that renders grids with cell and item objects
  • GridsViewController — controller that syncs model changes to the view

Custom grid objects

Override GridsViewController.createItemObjectOption() to return custom options for your grid items. Override GridObjectCreator methods in your view to create custom cell/item 3D meshes.

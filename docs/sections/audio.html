Audio

AudioService provides game audio built on the Web Audio API. It's created automatically by GamelabsApp and bound to diContainer.

Loading audio assets

// Use AssetTypes.Audio to load audio files (decoded to AudioBuffer)
this._assetRequestList.addRequest(
  new AssetRequest(AssetTypes.Audio, MyAssetIds.Jump, jumpUrl)
);
this._assetRequestList.addRequest(
  new AssetRequest(AssetTypes.Audio, MyAssetIds.BgMusic, musicUrl)
);

Playing sounds

const audio = resolver.getInstance(AudioService);

// Fire-and-forget SFX
audio.playSfx("MyGame.Jump");
audio.playSfx("MyGame.Jump", { volume: 0.5, rate: 1.2 });

// Background music (single track, looping by default)
audio.playMusic("MyGame.BgMusic", { fadeInMs: 500 });
audio.stopMusic({ fadeOutMs: 300 });

Volume control

audio.setMasterVolume(0.8);   // 0–1
audio.setSfxVolume(0.5);
audio.setMusicVolume(0.7);

audio.setMasterMute(true);
audio.setSfxMute(true);
audio.setMusicMute(false);

Browser autoplay policy

Browsers block audio playback until a user gesture. Call audioService.resume() on the first user interaction (click/tap). The service auto-pauses when the page loses visibility and resumes when it regains focus.

DSP integration

Insert a DspChain (from the audiodsp module) between sources and the gain nodes:

const chain = DspPresets.underwater(audio.context!);
chain.connectTo(audio.sfxGain!);
audio.setSfxDestination(chain.input);

API summary

  • playSfx(assetId, { volume?, rate?, loop? }) — play a sound effect
  • playMusic(assetId, { volume?, loop?, fadeInMs? }) — play background music
  • stopMusic({ fadeOutMs? }) — stop current music
  • setMasterVolume/setSfxVolume/setMusicVolume(0–1) — volume controls
  • setMasterMute/setSfxMute/setMusicMute(bool) — mute toggles
  • resume() — resume AudioContext after user gesture
  • pauseAll() / resumeAll() — suspend/resume all audio
  • setSfxDestination(node) / setMusicDestination(node) — insert DSP chains
  • context — the underlying AudioContext
  • sfxGain / musicGain — gain nodes for DSP chain wiring

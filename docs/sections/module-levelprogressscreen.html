Level Progress Screen

Level selection / progress screen showing a vertical list of level numbers with the current level highlighted and clickable. Includes a back button.

Usage

// Implement the model contract
class MyLevelModel implements ILevelProgressScreenModel {
  readonly visibleItemCount = 5;
  readonly currentLevel = 1;
}

const levelBinding = new LevelProgressScreenBinding(new MyLevelModel());
this.addModule(levelBinding);

// In postInitialize:
const events = this.diContainer.getInstance(LevelProgressScreenEvents);
events.onCurrentLevelClick(() => this.startLevel());
events.onBackClick(() => this.showMainMenu());

uiEvents.createScreen(LevelProgressScreenUIIds.LevelProgressScreen, transition);

Events

  • LevelProgressScreenEvents.onCurrentLevelClick(cb) — current level item tapped
  • LevelProgressScreenEvents.onBackClick(cb) — back button tapped

Customization

  • Model: implement ILevelProgressScreenModel (drives visibleItemCount and currentLevel)
  • Assets: override via assetRequestList.overrideRequest()
  • View: subclass LevelProgressScreenView and override layout/styling
